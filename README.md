# Vexora - Document Q&A with Gemma Model ✨

![image](https://github.com/user-attachments/assets/161d6588-c7ae-4d76-930f-7240e4a8287f)


## Overview
Vexora is an elegant Streamlit-based application that enables users to ask questions about PDF documents and receive accurate answers powered by Groq's Gemma2-9b-it model. The application uses advanced document processing techniques including text chunking, vector embeddings, and retrieval-augmented generation (RAG) to provide precise responses based on document content.

## Features
- **PDF Document Processing**: Automatically processes PDF files from a specified directory
- **Advanced RAG Architecture**: Implements a retrieval-augmented generation system for accurate answers
- **Vector Embeddings**: Uses Google's Generative AI Embeddings for semantic document understanding
- **Interactive Q&A Interface**: Clean, user-friendly interface for asking questions about documents
- **Document Similarity Search**: Shows the most relevant document chunks used to generate answers
- **Performance Metrics**: Displays response time for transparency
- **Beautiful UI**: Custom-styled interface with animations and gradient backgrounds
- **Responsive Design**: Adapts to different screen sizes for optimal user experience

## Technical Implementation
- Leverages Groq's Gemma2-9b-it large language model for high-quality responses
- Implements FAISS vector database for efficient similarity search
- Uses LangChain framework for seamless integration of various components
- Employs recursive character text splitting for optimal document chunking
- Integrates Google's embedding model for semantic understanding
